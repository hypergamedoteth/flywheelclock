Each block creates 3.125 BTC (the block subsidy since the April 2024 halving) and blocks arrive about every 10 minutes by design, so 3.125 ÷ 600 s = 0.0052 BTC a second. This is an estimate: blocks actually arrive at random. Since block 840,000 the average gap has been 596 s (derived from the timestamps of blocks 840,000 and 973,464), so real issuance runs a little faster. Transaction fees are extra and not counted here. The counter shows the target rate multiplied by time, not blocks found. 3 2

Checking supply from the rules

  • Subsidy: 50 BTC per block, halving every 210,000 blocks. 3
  • Blocks 0 to 839,999 (four full eras): 210,000 × (50 + 25 + 12.5 + 6.25) = 19,687,500 BTC
  • Blocks 840,000 to 973,464 at 3.125 BTC: 133,465 × 3.125 = 417,078.125 BTC
  • = 20,104,578.125 BTC if every subsidy was fully claimed (derived).
  • The API reports 20,104,543.0 BTC created. The gap of about 35 BTC is because some miners claimed less than the full subsidy; the API counts coins actually created. 1
  • Adding all 33 eras gives 20,999,999.9769 BTC, the exact cap (the subsidy is rounded down to whole satoshis, so it is just under 21 million).
